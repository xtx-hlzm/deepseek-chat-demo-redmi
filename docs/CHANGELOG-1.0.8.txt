DeepSeek Chat Demo 1.0.8 — 第三方站接入重写

第三方接入现由独立的配置存储、协议请求和设置界面模块处理。

使用：
1. 打开设置 → 第三方 API → 添加第三方接口。
2. 填写站点名称、协议、API 地址、密钥和模型。
3. 选择默认模型和推理强度，保存后即可聊天。
4. 修改已有站点时，编辑区展开在该站点卡片下面。
5. 需要特殊网关设置时展开“更多连接设置”，可指定认证、思考参数格式、超时、最大输出、流式/完整回复及专用接口地址。

协议：
- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- Gemini API

修复和改进：
- 每个站点独立记住所选模型和推理档位，切站后可恢复。
- 统一保存整份配置；保存失败会提示，避免显示已保存但实际未落盘。
- 自动读取旧版配置，保留站点 ID、密钥和模型列表。
- 普通网关别名模型也可明确选择其实际需要的思考参数格式。
- 获取模型和连接测试独立处理，测试实际调用所选模型，可能产生少量费用。
- 配置修改或模型切换后取消过期连接测试。
- 聊天请求绑定原站点，生成准备期间切换站点不会混用另一站点配置。
- Responses 的思考摘要先到、最终正文后到时，正文不会再被漏掉。
- 保留全局软键盘适配。

安装：沿用前几版修复 APK 的签名，可覆盖升级 1.0.6 / 1.0.7。

验证：15 组协议与配置测试通过；手机宽度下四协议模拟聊天和高级配置生效检查通过；APK 包内资源与测试资源一致，v1/v2/v3 签名通过。
未连接用户红米真机，未使用真实第三方密钥联网调用。不同站点和模型仍可能有各自的参数限制。
