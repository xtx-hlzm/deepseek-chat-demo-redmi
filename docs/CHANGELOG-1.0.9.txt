DeepSeek Chat Demo 1.0.9 — 切换应用后的对话连接恢复

修复：
1. 网络读取失败、后台连接断开、截断的数据与真正的协议格式错误分别处理，减少“协议选错”的误报。
2. 切到后台导致连接中断，尚未收到内容时，回前台自动重新发送一次原请求。站点、模型、协议和密钥保持原请求配置。
3. 已经收到内容时不自动重发，保留文字并提示连接中断，可点击重新生成。
4. 回前台后的旧连接长时间无响应时结束失效连接，避免界面一直卡住。
5. 收到流式完成标记后及时结束，不再等待中转站关闭长连接。
6. 用户主动取消、密钥错误或真正的格式错误不会触发后台自动重试。
7. 第三方站“更多连接设置”可关闭“切换应用后的连接恢复”。自动重发可能产生额外 API 费用。

安装：沿用此前修复版签名，可直接覆盖升级 1.0.8。

验证：23 组协议、配置及恢复测试通过；浏览器模拟后台断流、返回前台恢复、部分文字保留以及四协议聊天流程检查通过；安装版本与包内资源一致，v1/v2/v3 签名通过。

尚未在用户红米手机上实测。系统强行终止整个应用进程时，无法保证原网络连接继续；重新打开后可查看已保存内容并重新生成。
